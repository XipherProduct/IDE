## Что такое Xipher IDE?

Xipher IDE — бесплатный open-source инструмент командной строки, который даёт доступ к **75+ AI-моделям** от **7 провайдеров** — прямо из терминала.

Вместо того чтобы переключаться между вкладками браузера или использовать отдельные CLI для каждого провайдера, Xipher IDE предоставляет единый интерфейс.

## Поддерживаемые провайдеры

- **OpenAI** — GPT-4o, GPT-4o-mini, o1, o3-mini
- **Anthropic** — Claude 4 Opus, Claude 4 Sonnet, Claude 3.5 Haiku
- **Google** — Gemini 2.5 Pro, Gemini 2.0 Flash
- **DeepSeek** — DeepSeek-V3, DeepSeek-R1
- **xAI** — Grok-3, Grok-3-mini
- **Zhipu AI** — GLM-4-Plus, GLM-4-Flash
- **Moonshot** — Kimi k2

## Быстрый старт

1. Установите Xipher IDE
2. Добавьте API-ключ через `xipher configure`
3. Начните диалог командой `xipher`

Всё! Перейдите на страницу [Установка](/ru/docs/installation) для подробных инструкций.
