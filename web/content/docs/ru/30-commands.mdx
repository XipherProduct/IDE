## Запуск чата

```bash
xipher
```

Запускает интерактивную сессию. Вам предложат выбрать модель, после чего можно начинать диалог.

## Слэш-команды

Во время чата доступны слэш-команды:

### /model

Переключиться на другую модель:

```
/model gpt-4o
```

### /system

Задать или изменить системный промпт:

```
/system Ты — полезный ассистент по программированию
```

### /history

Просмотр истории диалогов:

```
/history
```

### /clear

Очистить текущий диалог:

```
/clear
```

### /help

Показать доступные команды:

```
/help
```

### /exit

Выйти из чата:

```
/exit
```

## Горячие клавиши

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+C` | Отменить текущий ответ |
| `Ctrl+D` | Выйти из чата |
| `Up/Down` | Навигация по истории ввода |

## Флаги CLI

```bash
xipher --version     # Показать версию
xipher --help        # Показать справку
xipher configure     # Настроить API-ключи
```
