## What is Xipher IDE?

Xipher IDE is a free, open-source command-line tool that gives you access to **75+ AI models** from **7 providers** — all from your terminal.

Instead of juggling browser tabs or maintaining separate CLIs for each AI provider, Xipher IDE provides a single, unified interface.

## Supported Providers

- **OpenAI** — GPT-4o, GPT-4o-mini, o1, o3-mini
- **Anthropic** — Claude 4 Opus, Claude 4 Sonnet, Claude 3.5 Haiku
- **Google** — Gemini 2.5 Pro, Gemini 2.0 Flash
- **DeepSeek** — DeepSeek-V3, DeepSeek-R1
- **xAI** — Grok-3, Grok-3-mini
- **Zhipu AI** — GLM-4-Plus, GLM-4-Flash
- **Moonshot** — Kimi k2

## Quick Start

1. Install Xipher IDE
2. Add your API key with `xipher configure`
3. Start chatting with `xipher`

That's it! Head to the [Installation](/en/docs/installation) page for detailed setup instructions.
