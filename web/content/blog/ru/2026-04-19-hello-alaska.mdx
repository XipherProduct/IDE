## Добро пожаловать в Xipher IDE

Сегодня мы публично запускаем **Xipher IDE v0.4.0** — первую публичную альфу инструмента, который мы создали, чтобы решить проблему, знакомую многим разработчикам: фрагментацию доступа к AI.

## Проблема

Если вы регулярно работаете с AI-моделями, то вероятно:

- Держите открытыми вкладки с ChatGPT, Claude и Gemini
- Платите за несколько подписок
- Копируете текст между окнами
- Теряете полезные ответы в разных чатах

## Наше решение

Xipher IDE даёт **единый терминальный интерфейс** для всех основных AI-провайдеров:

```bash
$ xipher
Xipher IDE v0.4.0
Выберите модель:
  1. gpt-4o
  2. claude-4-sonnet
  3. gemini-2.5-pro
  4. deepseek-r1
  ...
```

Браузер не нужен. Ваши API-ключи хранятся безопасно в системном keyring. Стриминг ответов в реальном времени с отменой через `Ctrl+C`.

## Что в v0.4.0?

- **75+ моделей** от 7 провайдеров (OpenAI, Anthropic, Google, DeepSeek, xAI, Zhipu, Moonshot)
- **Безопасное хранение ключей** в системном keyring
- **Стриминг** с поддержкой отмены
- **Слэш-команды** — `/model`, `/system`, `/history`, `/clear`
- **Кроссплатформенность** — macOS, Linux, Windows

## Начало работы

Установка в одну строку:

```bash
curl -fsSL https://raw.githubusercontent.com/xipher-pro/xipher-ide/main/install.sh | sh
```

Настройте первого провайдера:

```bash
xipher configure
```

И начинайте общение:

```bash
xipher
```

## Что дальше?

У нас амбициозная дорожная карта:

- **Tool calling** — вызов функций моделями
- **/attach** — отправка файлов в контекст
- **Мультимодальность** — изображения и другие форматы
- **SQLite-сессии** — персистентные сессии с полным контекстом
