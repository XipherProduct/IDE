три движения

От вопроса до коммита — три действия.

Никаких «открой панель, выбери модель, скопируй файл, вставь, опиши контекст». Чат уже внутри редактора, индекс уже построен, история уже сохранена.

01 · ИНДЕКС

Открыли проект — индекс готов.

ALaska читает структуру за секунды и обновляется по мере правок. Никаких ручных «добавь файл в контекст».

02 · ЧАТ

Спросили — получили ответ со ссылками.

Чат отвечает с цитатами файлов и строк. Можно перетащить любой файл прямо в окно и продолжить разговор.

возможности

Не «ещё одна IDE с ИИ». Шесть конкретных решений.

Каждая ячейка ниже — отдельная фича, которую мы целенаправленно делали для разработчика в России: с моделями OpenAI без VPN-боли и с честной локальной телеметрией.

01размер бинарника

160 МБ — и это весь редактор.

Один файл, без menulibs и подграфов зависимостей. Скачивается за пару минут даже с северной мобильной сетью.

IDE «J». ~580 МБ
Vim-форк X. ~365 МБ

Чат, inline-правка, файл-пикер и палитра команд — на расстоянии двух клавиш. Привычные шорткаты VS Code не сломаны.

05OpenAI

Без VPN-плясок.

Прямые маршруты к GPT 5.5, 5.4 и 5.4 mini через нашу инфраструктуру. Один счёт, без танцев с прокси и валютой.

06совместимость

Все расширения VS Code на месте.

Settings Sync, темы, devcontainers, удалённая разработка по SSH. Открываете свой .vscode/ — всё работает.

07приватность

Код не уезжает в облако без вашего ведома.

В модель улетают только те куски, что вы явно прикрепили. Локальный индекс остаётся на машине — это аудируемо: открыли вкладку «телеметрия» и увидели каждый отправленный байт.

    телеметрия

    Видно, что и куда уходит. До последнего байта.

    Никакого «мы собираем анонимные данные для улучшения продукта». Внутри ALaska — настоящая панель телеметрии, где видно каждый запрос: что ушло, кому, сколько токенов, сколько денег.

    Прозрачность как фича, а не маркетинг.

    Каждое обращение к модели логируется локально. Видно, какие файлы прикрепились к запросу, какие команды выполнил агент, сколько стоил ответ. Кнопка «отключить телеметрию» делает ровно то, что написано — никаких звёздочек.

    • Полный журнал запросов и ответов — экспорт в JSON.
    • Лимиты по проекту, по дню, по модели.
    • Сторонним аналитическим сервисам — ничего. Даже нам.
    • GPG-подписанные сборки, чтобы вы могли проверить, что бинарник наш.
