Скачать ALaska.

Один бинарник в 160 МБ. Без админских прав на Windows, без menulib-зависимостей на Linux. Скачали — запустили — открыли проект.

установка одной строкой

Для тех, кто дома в терминале.

Скрипт берёт ваш ARCH, скачивает нужный билд, проверяет sha256 и кладёт в ~/.alaska. Никаких sudo.

~ $ curl -L alaska.ai/get | sh
→ обнаружено: linux-x86_64
→ загрузка ALaska-0.42.1-x86_64.AppImage…
0 160 МБ
→ sha256: ok
→ gpg: подпись валидна
→ установлено в ~/.alaska
✓ запустите: alaska .  в любой папке проекта
системные требования

Что нужно, чтобы запустить.

Низкие, как у обычного редактора. Без отдельных GPU-требований — модели крутятся не у вас.

osсистемы

Win 10+ / Linux glibc 2.31+

На Windows 7/8 не запустится. Альт Линукс, Astra, Ubuntu 20.04+, Fedora 36+ — да.

ramпамять

4 ГБ минимум, 8 ГБ норма

Редактор плюс индекс среднего репозитория умещается в 1–2 ГБ. Остальное — для остальных вкладок.

cpuпроцессор

x64 или ARM64

Тестируем на i5-8xxx, Ryzen 5 первой ревизии, и Apple Silicon (через мультипасс).

netсеть

Прямой доступ в интернет

VPN не нужен — мы сами роутим запросы к OpenAI. Для off-grid режима оффлайн-индекс работает без сети.
